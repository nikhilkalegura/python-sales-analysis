# Sales Data Analysis Using Python

## Project Overview
This project analyzes sales transaction data to identify business trends, product performance, regional profitability, customer contributions, and discount patterns.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- CSV datasets
- Visual Studio Code

## Dataset
The dataset contains 1,000 sales records with information about orders, customers, products, regions, quantities, categories, prices, discounts, sales, and profit.

## Data Cleaning
- Checked for missing values.
- Checked for duplicate records.
- Converted order dates to datetime format.
- Created year, month, and month-name columns.
- Exported the processed dataset to CSV.

## Analysis Performed
- Overall sales and profit KPIs
- Monthly sales trends
- Product-wise sales and profit
- Regional sales and profit
- Customer sales and profitability
- Discount analysis
- Regional profit margins
- Category performance
- Product profitability
- Final business insights

## Key Findings
- Total sales: ₹45,765,310
- Total profit: ₹7,385,292.01
- Total orders: 1,000
- Total quantity sold: 3,031
- Highest-sales month: August
- Lowest-sales month: November
- Highest-sales product: Laptop
- Highest-sales region: South
- Highest-profit region: West

## Business Value
The analysis demonstrates how Python can be used to clean data, calculate performance metrics, identify trends, visualize results, and support business decisions.

## Disclaimer
The dataset is used for educational and portfolio purposes. Findings should be interpreted as illustrative rather than evidence about a real business.
